HireLens
A small website for a university web technologies project. HireLens is an imaginary resume screening tool that ranks resumes against a job description and explains each score.

Reg No. L1f24bscs0278 & L1f24bscs0055
Course: Web Technologies
Page
index.html - home page
media.html - how HireLens works (image, video, audio, lists and a table)
register.html - recruiter sign-up form
services.html - what HireLens offers
portfolio.html - screening mockups
contact.html - contact form
style.css - the external stylesheet used by all pages
